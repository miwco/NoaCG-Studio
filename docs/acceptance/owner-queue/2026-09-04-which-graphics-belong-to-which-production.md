# Which graphics belong to which production, from the library

You said today it was hard to see which graphics were part of which production, and that the only
way to find out was to open the playout system and play them one by one. The library now answers
it without leaving Home.

## The route, in under a minute

1. Open `/app`, then **Graphics** in the left nav.
2. Every card that is in a production now carries that production's name as a pill under the
   graphic's name. A graphic in none carries nothing.
3. In the header row, beside Sort, there is a **Production** dropdown. Pick one: the list narrows
   to that production's graphics, across folders, and the folder band steps aside while it stands.
4. Pick **Not in a production** at the bottom of that same dropdown: that is every graphic no
   production holds. Nothing is hidden by picking a production - this is the way back to the rest.
5. Click any production pill on a card - it filters to that production too.
6. Switch to the table view (the list icon, top right): there is a **Productions** column, with
   an em dash where a graphic is in none.
7. Go to **Productions** in the left nav. On any production card, the "**N graphics**" line is now
   a link: it opens the library already narrowed to that production.

## What to look at

Whether this is how you would want to check a production before a show - and in particular
whether the pill on a card is the right amount of information, or whether you would rather see
the count than the name. On a graphic in three or more productions the card prints two names and
a `+1`; the table prints one and the rest as a number, with the full list on hover.

One thing that is deliberately NOT here: this lists the graphics of a production that still exist
in your library. A production also holds its own copy of everything, and a copy whose library
graphic was deleted keeps airing but cannot be listed here. Where those two numbers differ, the
production card says so on its own line rather than quietly showing you fewer.
