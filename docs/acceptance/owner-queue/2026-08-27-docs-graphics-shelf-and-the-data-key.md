# The /docs left nav, and a production's data key

Two things, one walk, about a minute each.

**1. The docs left nav.** Route: open `/docs`. What to look at: the left nav now carries main
topics only, and end credits and tickers are gone from it. They are guides INSIDE one
**Graphics** section, which also has scoreboards and quizzes and game shows, with a contents
list at the top of the section. Read the "Quizzes and game shows" guide: it is the kind the
student production runs, and it names every button an operator presses.

**2. The data key is in the product.** Route: a PUBLISHED production, its **Data** tab, then
`▾ Data key` in the Production data panel. What to look at: the key is hidden until Reveal, and
Copy says so. Before this it existed only as a database row, so the whole Production Data API
guide described something a hosted user could not do.
