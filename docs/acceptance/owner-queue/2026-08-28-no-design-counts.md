# The catalog is described, not counted

many designs we have. Two public surfaces carried a count and both are rewritten.

**Look at, in order:**

1. **https://github.com/miwco/NoaCG-Studio** - the "What's in it" list. The first bullet was *507
   designs across 22 categories*. It now reads "A catalog that covers a whole show, and keeps
   growing", then the same list of what is actually in it. The question: does dropping the number
   cost the line anything, or was the list always the useful half?
2. **The landing page, the "Start from a template" card** (the three-doors section, roughly a
   third of the way down `/`). It said *Hundreds of broadcast-grade designs*. Vague, but still a
   claim about amount, so it now says "Broadcast-grade designs for every part of a show".

Nothing else public carried a count. The build gate now refuses a new one, so this cannot come
back with the next catalog milestone - and today's build prerendered 503 template pages, not 507,
which is the drift the old number was already carrying.
