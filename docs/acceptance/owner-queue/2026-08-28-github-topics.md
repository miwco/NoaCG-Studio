# GitHub topics on the repository

Applied 2026-08-28 with `gh repo edit --add-topic`, on your delegation ("if there's something
logical"). Live already - this is not waiting on a merge.

**Route (under a minute):** open https://github.com/miwco/NoaCG-Studio and look at the About box
on the right, under the description.

**The nine topics, in the order GitHub sorts them:**

`broadcast-graphics` `casparcg` `character-generator` `live-production` `motion-graphics`
`obs-studio` `ograf` `spx-graphics` `vmix`

The reasoning: five are the names somebody searches when they already have the problem
(`casparcg`, `spx-graphics`, `ograf`, `obs-studio`, `vmix`), and four are what the project is
(`broadcast-graphics`, `motion-graphics`, `live-production`, `character-generator`). No topic
claims AI, teaching or a framework, because none of those is what a person would be looking for
when they land here.

**The question:** is anything on that list wrong or missing? Removing one is
`gh repo edit --remove-topic <name>`.
