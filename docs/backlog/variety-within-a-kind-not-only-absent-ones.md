# The gallery needs more variety WITHIN kinds, not only the absent ones

**Filed:** 2026-09-04. **Source:** owner, accepting the twelve ranked absences and saying they are
not the whole job.

## Why

`docs/CATALOG_BY_PROGRAMME.md` §6 ranks twelve silhouettes the catalog does not have at all. A
weekly row that only ever closes one of those never touches the thing the owner has complained
about twice: the designs we DO have are all the same design.

The measurement is already in that document, §7. 93% of lower thirds are one silhouette. There are
101 straps. Adding an over-the-shoulder box does not make the 102nd strap any less like the other
101.

He is explicit that this is the hard kind of work and not a prompt:

> This is very difficult. We need to be creative and look at references and stuff like that, and it
> takes time.

So this is not a row that can be handed to a mechanical worker with a recipe. It needs references,
a point of view, and a look that is a deliberate departure rather than a parameter change.

## What it would take

The open question is what a "different lower third" even means here, and it should be answered
before any drawing. Candidates, none decided: a different anchor (upper, side, centred rather than
lower-left); a different ground (cutout, gradient wash, full-bleed colour, transparent with a rule
only); a different entrance grammar; a different type register entirely (condensed, serif,
all-caps display). §8's register work and `docs/CATALOG_VARIETY.md` are the nearest existing
thinking.

Then the same package discipline as §9: a set that runs a show, in one look, not one card.

Pairs with `docs/backlog/catalog-variety-by-programme-type.md`, which carries his 2026-09-03
version of the same complaint, and with each design's own default palette and entrance so the
Browse thumbnails stop converging.
